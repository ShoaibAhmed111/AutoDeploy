How to trigger the pipeline & see changes here
1
Start everything (do this every time you open your computer)
Open Docker Desktop and wait for it to load. Then double-click start-autodeploy.bat in your project folder. It starts Jenkins and fixes permissions automatically.
2
Make a code change
Edit any file in your project — for example change the message in app/src/server.js on the /api/message route. Then push to GitHub:
git add .
git commit -m "my change"
git push
3
Jenkins detects the push automatically
Jenkins polls GitHub every minute. Within 60 seconds it will detect your push and start the pipeline automatically. You can also go to http://localhost:8080 → AutoDeploy → click Build Now to trigger it instantly.
4
Watch it here in real time
This page auto-refreshes every 5 seconds. You will see each stage turn green as it passes. When all 7 stages are green, your new code is live at http://localhost:3000. The build history below shows all previous runs.
